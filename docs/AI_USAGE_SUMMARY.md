# AI Usage Summary

AI tools were used as development assistance throughout the AI Crypto Advisor project, while human developer reviewed the implementation, ran tests, debugged errors, deployed the application, and made final decisions.

## Tools Used

- ChatGPT was used for planning, architecture discussion, debugging support, deployment guidance, documentation wording, and writing structured Codex prompts.
- Codex was used for code generation, refactoring and test updates based on explicit prompts and project requirements.

## Areas Assisted By AI

AI assistance was used for several parts of the project, including:

- Designing the FastAPI backend structure with routers, services, repositories, SQLAlchemy models, Pydantic schemas, and mapper functions.
- Implementing and refining authentication, onboarding preferences, dashboard data, and feedback voting flows.
- Improving OpenRouter AI Insight behavior, including response validation, output cleanup, caching, retry logic, and safe fallback handling.
- Building and polishing the React + Vite frontend pages, components, API client structure, authentication context, dashboard layout, and voting UI.
- Troubleshooting deployment considerations for Render and Vercel.
- Preparing concise public documentation for the final submission.

## Human Review and Verification

The developer guided the feature scope, reviewed generated code, tested the backend and frontend, debugged runtime issues, configured deployment services, and decided which tradeoffs were appropriate for the assignment. AI assistance accelerated implementation and helped structure the work, but the developer remained responsible for verification, final behavior, security checks, and deployment readiness.
